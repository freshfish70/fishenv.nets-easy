# Nets Payment Library

This library is a wrapper around the Nets Payment API, and provides a simple
interface for creating payments, getting payments, canceling payments,
terminating payments, charging payments, refunding payments, updating payments,
and deleting payments.

It is meant to be used as a library.

API documentation:
https://developer.nexigroup.com/nexi-checkout/en-EU/api/payment-v1/
or 
./nets.md for local version of the documentation.
